How to use

Start typing after selecting Plume Française from the input menu. The candidate window updates as you go.

  • ↑ / ↓ — move through candidates.
  • 1–9 — pick a candidate on the current page directly.
  • Space — commit the highlighted candidate and insert a trailing space.
  • Return — commit without adding a space.
  • Escape — cancel the current composition.
  • Typing ;, :, ! or ? after a word commits it with French spacing automatically.

Grammar

French agreement rules depend on your own gender when you're the subject (for example je suis allé vs je suis allée). This only changes suggestions for "je", "tu" and "on" in compound tenses built with être — everything else is unaffected.
